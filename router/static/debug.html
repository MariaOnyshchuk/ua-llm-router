What am I looking at?
  1. You type a request. Three small Ukrainian models are available; each is good at different things.
  2. The router reads the request, decides what kind it is (translation, facts, ethics, writing with rules, code, conversation) and sends it to one model. The chosen model is highlighted in yellow, with the reason.
  3. Most requests need one model call. If a request clearly contains several tasks that depend on each other ("translate this, then explain it"), the mode Plan steps if needed splits it into steps and shows each step.
  4. Compare with one model sends the same request to the router and to one model you pick, side by side.
