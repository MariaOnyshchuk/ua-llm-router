# scripts/ map

Run everything from the repo root. `python scripts/<name>.py --help` for options.

| Folder | What is there |
|---|---|
| `scripts/` (top level) | Live pipeline: run models and routers (`run_small_router_cluster.py`, `run_composite_router.py`), score (`score_results.py`, `score_repeat_dir.py`, `aggregate_repeat_scores.py`, `score_composite_results.py`), v6 suite build and evaluation (`sample_screening_suite.py`, `curate_discriminative_suite.py`, `extract_full_corpora.py`, `extract_ua_leaderboard.py`, `build_router_comparison.py`), ledger and publishing (`build_progress_ledger.py`, `publish_hf_eval.py`), AgentCoMa step questions alone (`run_agentcoma_steps.py`), debug UI without GPUs (`mock_backends.py`; then `uvicorn router.app:app --port 4010` and open `/debug`), prompt variants (`alignment_prompt_variants.py`, `bucket_prompt_variants.py`), Wikipedia cache and retrieval check for `--wiki-rag` runs (`build_wiki_cache.py`), helpers (`mcq_format.py`, `ifeval_check.py`, `sample_size_ci.py`), log viewer (`log_viewer.html`: open in a browser and drop `logs/` or a `results/<group>/` folder on it; reads files locally, no server) |
| `scripts/analysis/` | Statistics and plots for the text: `bootstrap_compare.py` (paired bootstrap intervals, v4 only), `plot_tradeoff.py`, `routerbench_dev.py` and `plot_routerbench_dev.py` (kNN and MLP quality predictors as in RouterBench, λ·P − cost curves, Zero router, AIQ; v7 dev only, offline) |
| `scripts/benchmarks/` | Build of the small v0 to v4 suites, run once: `sample_*.py`, `build_balanced_suite.py`, `merge_benchmarks.py`, `import_english_code.py`, `check_router_leakage.py`. Also `build_mixed_ua_v7.py` (claim suite v7: whole pool, dev/test split). `build_composite_test100.py`: the held-out composite test set (same schema, no overlap with graph-100 or v7). `build_composite_graph100.py`: the 100-item composite graph set (simple/chain/graph/parallel × 25). `render_composite_viewer.py`: one-page HTML viewer of a composite benchmark with per-item system scores (output in `benchmarks/viewers/`, not tracked). `prompts/composite_generation.md`: teacher prompts for the 100-request composite dataset (draft, STaD-style checks) |
| `scripts/archive/` | Superseded or one-off scripts from weeks 1 to 9, and scripts of experiments that were dropped (moved 29 Oct 2026): `first_token_confidence.py` (confidence-based model choice, no gain), `estimate_route_table.py` (per-source route table, not pursued), `v6_compare.py` and `week_v6_eval_pipeline.sh` (v6, withdrawn 12 Oct), `train_learned_router.py` (`knn`/`clf` profiles, never used). Kept for history, not part of the pipeline. Paths inside them may be stale |
| `cluster/archive/` | Slurm jobs of dropped experiments (moved 29 Oct 2026): `eval_v6_router.sbatch`, `eval_v6_solo.sbatch` (v6, withdrawn), `serve_*_bnb.sbatch` (bitsandbytes 4-bit, slower and lower than bf16). Paths inside them may be stale |

Cluster jobs are in `cluster/`. The claim suite is v7 (test split); v6 is withdrawn. See `AGENTS.md`, section Evidence rules.
